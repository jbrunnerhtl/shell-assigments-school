# shell-assigments-school
Small collection of POSIX-compatible shell scripts created as school assignments.

## Quick start

- Clone: git clone https://github.com/JBrunnerhtl/shell-assigments-school.git
- Run a script: sh <script>.sh [args...] or chmod +x <script>.sh && ./<script>.sh [args...]

## Requirements

- POSIX-compatible shell (sh)
- Unix-like environment (Linux, macOS, WSL)

## Contributing

- Open an issue or PR. Keep scripts POSIX-compatible and update usage comments.
